# Задача: Розробка SPFx вебчастини для роботи з даними SharePoint

## Мета

Створити SPFx-рішення для SharePoint Online, яке дозволяє користувачам переглядати, створювати, редагувати та видаляти записи зі списку SharePoint через сучасний інтерфейс на базі **ag-Grid**. У рішенні повинні використовуватися форми введення даних, довідники та каскадні випадаючі списки.

---

## Основний функціонал

### Відображення даних
- Відображення даних SharePoint списку в ag-Grid.
- Сортування по колонках.
- Пошук та фільтрація даних.
- Оновлення даних без перезавантаження сторінки.

### Робота з записами
- Створення нового запису.
- Перегляд існуючого запису.
- Редагування запису.
- Видалення запису з підтвердженням дії.

### Форми
- Окремі режими **Create / Edit / View**.
- Завантаження довідників із SharePoint.
- Валідація обов'язкових полів.
- Відображення повідомлень про помилки та успішні операції.

---

## Структура даних

Основний список повинен містити:
- не менше **10 полів**;
- не менше **5 різних типів полів**.

**Приклади типів:**
- Текстове поле;
- Багаторядковий текст;
- Lookup;
- Choice;
- Number;
- DateTime;
- Person or Group;
- Yes/No.

---

## Довідники

Для значень випадаючих списків використовуються окремі SharePoint списки-довідники.

**Приклади:**
- Категорії;
- Підкатегорії;
- Статуси;
- Організаційна структура;
- Інші довідкові дані.

---

## Каскадні списки

Реалізувати залежність між випадаючими списками.

**Наприклад:**

```
Категорія
   ↓
Підкатегорія
```

При зміні батьківського значення:
- дочірній список оновлюється;
- попереднє значення очищається;
- доступні тільки дозволені значення.

> Каскади повинні працювати як при створенні, так і при редагуванні записів.

---

## Валідація

Налаштувати перевірки для кількох полів:
- обов'язковість заповнення;
- перевірка формату даних;
- перевірка числових значень;
- перевірка дат;
- логічні перевірки між полями.

> Користувач повинен бачити повідомлення про помилки до збереження запису.

---

## Фільтрація в ag-Grid

Реалізувати декілька типів фільтрів:

| Тип фільтра | Призначення |
|---|---|
| Текстовий фільтр | Для текстових колонок |
| Випадаючий список | Для полів типу Choice або Lookup |
| Множинний вибір | Для полів, де потрібно обрати декілька значень |
| Дата | Для фільтрації по датах |
| Числовий фільтр | Для числових полів |

---

## Інтеграція із SharePoint

Використовувати стандартні механізми SharePoint:
- читання елементів списку;
- створення записів;
- оновлення записів;
- видалення записів;
- завантаження довідників;
- робота з Lookup та User полями.

---

## Вимоги до інтерфейсу

- сучасний дизайн на **Fluent UI**;
- індикатори завантаження;
- повідомлення про помилки;
- повідомлення про успішні операції;
- адаптивне відображення;
- робота в SharePoint Modern.

---

## Очікуваний результат

Після завершення робіт користувач повинен отримати вебчастину, яка дозволяє:
- працювати зі списком SharePoint через ag-Grid;
- використовувати форми Create/Edit/View;
- використовувати каскадні випадаючі списки;
- виконувати CRUD-операції;
- застосовувати різні типи фільтрів;
- працювати без переходу на стандартні форми SharePoint.
